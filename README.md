# Michael Tejada — Portfolio

The source code for my personal portfolio site. I'm a developer in the Philippines who builds full-stack products and the AI automations that run them.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Vercel

## Run locally

```bash
npm install
npm run dev
```
